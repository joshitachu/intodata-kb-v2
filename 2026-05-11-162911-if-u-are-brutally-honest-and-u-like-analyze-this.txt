  ---
  Overall: ~55–60% enterprise-ready

  The foundations are solid — async Python, JWT/bcrypt/TOTP, Pydantic v2, 22
  Alembic migrations, Qdrant RBAC filtering. But the codebase has the classic
  shape of fast MVP development: auth done well, observability absent, testing
  shallow, and two backend workflows explicitly stubbed in code.

  ---
  Three Things Broken Right Now

  1. Privilege escalation bug — HIGH severity
  RAG_pipeline/backend/src/api/routes/documents.py:61–81 — the DELETE endpoint
  checks CurrentUser but never verifies the document belongs to a project the
  user has access to. A developer in Project A can delete documents from Project
   B if they guess the ID.

  2. Onboarding ingest is fake
  src/services/onboarding_service.py and system_config_service.py both have
  explicit TODOs: "TODO: wire up to real ingest pipeline. For now simulates work
   then marks complete." The "add your documents" step in onboarding silently
  pretends to work.

  3. Deployment never validated on a clean machine
  deploy/RUNBOOK.md + CLAUDE.md both say EP-001 is not accepted until tested on
  a fresh VPS. That has never happened. The deployment is assumed to work, not
  known to work.

  ---
  What's Actually Good

  - JWT + refresh rotation + httpOnly cookies: properly done
  - TOTP with replay protection (90-second window, last-code stored)
  - Rate limiting on login (5/min) and query (30/min)
  - Async throughout — no blocking I/O
  - Resource limits in docker-compose (mem_limit, cpus)
  - Credential filtering in intodoc scanner (regex + structural, paranoid mode)
  - 22 sequential Alembic migrations — clean schema history

  ---
  Should You Change the Backend Language?

  No. The Python/FastAPI stack is correct for this product. The entire AI/ML
  ecosystem (embeddings, reranking, LLM clients, Qdrant SDK) is Python-native.
  Switching to Go means reimplementing or wrapping all of it. The actual
  performance ceiling is Qdrant query latency and Ollama inference — both are
  I/O-bound and language-agnostic. A rewrite would cost 6–12 months with zero
  feature delivery. The gaps are operational maturity and missing features, none
   of which are solved by language change.
