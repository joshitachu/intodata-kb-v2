01

Login

When you open Nexus in your browser you will see the login screen. Enter your username and password to get started.

  1. Open Nexus in your browser

    Navigate to the URL provided by your administrator (e.g. https://nexus.yourcompany.com).

  2. Enter your username and password

    Your administrator provisions your account and role for your organisation's domain.

  3. Complete two-factor authentication (if enabled)

    If multi-factor authentication is required, enter the 6-digit code from your authenticator app, or use a backup code. You can set this up under Settings → Security.

  4. Click "Login"

    After a successful login you are redirected to the Chat page.

Good to know Your session stays active for 60 minutes and refreshes automatically for up to 7 days. After that you will need to log in again. Don't have an account yet? Ask an admin to create one for you.

03

Chat

The Chat page is the landing page of Nexus and provides a unified experience for asking questions about your documents. Switch between Chat mode (quick RAG queries) and Deep Dive mode (in-depth project analysis) directly from the input bar.

The Chat welcome screen: a centered prompt, suggestion chips, and the input bar with the Chat/Deep Dive toggle and project filter

How to use Chat

  1. Start a new conversation

    Click "+ New Chat" in the sidebar, or simply start typing in the centered input on the welcome screen.

  2. Choose a mode

    In the input bar you will see two options: Chat and Deep Dive.

    • Chat — Quick RAG query. The system finds relevant sections from your documents and generates an answer.
    • Deep Dive — In-depth analysis of a specific project. Uses more context for richer answers.
  3. Filter by project (optional)

    Use the project dropdown in the input bar to search only within a specific project.

  4. Ask your question

    Type a question and press Enter, or click one of the suggestion chips to get started. Examples:

    • "What projects are available?"
    • "How do the integrations connect?"
    • "What does the job LoadCustomerData do?"
  5. Attach an image (optional)

    Use the image button to attach a screenshot or diagram (JPEG, PNG, GIF or WebP, up to 4 images). Nexus can analyse the image alongside your question.

  6. View the live answer

    The answer is streamed word by word, with numbered source citations you can click to jump to the underlying document.

  7. Ask follow-up questions

    Chat remembers your context. Ask things like "Can you tell me more about that?" or "What about the connections?"

Chat vs. Deep Dive — when to use which?

💬 Chat

  • Quick questions across all documents
  • Remembers conversation context
  • Faster response
  • Ideal for lookups and general questions

🔍 Deep Dive

  • In-depth analysis of a specific project
  • Uses more context for detailed answers
  • Richer, more comprehensive output
  • Ideal for complex, project-wide analyses
Tips for better results Ask specific questions. Use project filtering when you have many projects. Use Deep Dive for complex, project-wide analyses, and click a suggestion chip to get started quickly.

Documents

On the Documents page you upload and manage the files that become searchable in Chat.

The Documents page: select a project, upload a file, and browse the Document Library below

Uploading a document

  1. Select a project

    Choose the project the document belongs to in the dropdown at the top.

  2. Choose a document role (optional)

    Tag the file by how it should be used — source (project evidence, the default), reference, guidance, standard, template or policy. Roles help Nexus decide which documents prove facts versus which shape interpretation.

  3. Upload your file

    Drag the file into the upload area, or click the area to browse.

  4. Automatic processing

    The file is split into chunks, embedded into vectors, and becomes immediately searchable.

Supported file formats

Document Library

At the bottom of the page you can see all uploaded documents with filename, type, role and chunk count. Click the trash icon to delete a document — it is removed from both the database and the vector store.

Note You can only upload documents for projects assigned to you. Ask an admin for project access if you don't see a project in the dropdown.

Topology

The Topology page provides an interactive visual map of your project structure. It shows how jobs, connections and groups relate, making complex integration projects easy to understand at a glance.

The Topology page: project selector, view modes, group filter chips, search bar, and an interactive graph with legend

How to use Topology

  1. Select a project

    Choose a project from the dropdown. You will see the platform type and number of jobs (e.g. "esb-main (talend, 21 jobs)").

  2. Choose a view mode

    Switch between views from the toolbar:

    • Overview — High-level view with groups collapsed into summary nodes
    • Detail — Expanded view showing individual jobs within groups
    • Top-Down — Hierarchical layout from top to bottom
    • Conn — Focus on connections and their relationships
  3. Filter by group

    Click the coloured group chips to show or hide groups. Click "Reset" to show all.

  4. Search for nodes

    Use the search bar to find specific jobs or connections by name.

  5. Interact and navigate

    Click a group node to expand it. Use scroll to zoom, drag to pan, and the Fit button to frame the whole graph. A minimap helps you orient in large graphs.

Tip Start in Overview mode for large projects to see groups and their connections, then switch to Detail mode to drill into specific areas.

Settings & Admin

Settings provides system health, account security, usage analytics, runtime logs and benchmark results. The Admin section (admin-only) lets you manage users, roles and projects.

Security & your account

Under Settings → Security you can enable multi-factor authentication (MFA). Scan the QR code with an authenticator app and store the one-time backup codes safely — they let you sign in if you lose your device.

For administrators Depending on your deployment, MFA may be mandatory. When enforced, users must complete enrolment before they can use the rest of the app.

AI providers & data flow

Nexus uses a configurable provider chain so each deployment can balance quality, cost and data residency:

StageDefault (cloud)Local-only option
EmbeddingsVoyage AI voyage-4-largeOllama nomic-embed-text
RerankingVoyage AI rerank-2.5Disabled / local
Answer generationCloud LLM (e.g. Anthropic Claude)Ollama (e.g. gemma3:12b)
Data residency When cloud providers are enabled, query text and relevant document chunks are sent to those providers to compute embeddings and answers. If your data must not leave your environment, your deployment can run fully local using Ollama for both embeddings and generation. Ask your administrator which configuration is active, and validate any regulatory requirements (e.g. GDPR) with your compliance team.

Frequently Asked Questions

How do I add a new project?

Open the Nexus Dashboard, click "Add Repo", enter the project name and path to the source code, select the platform type (Talend, Workato, etc.) and save.

Why am I not getting results?

Check that documents have been uploaded for the selected project, try different phrasing, and confirm the correct project is selected in the filter. On the Documents page, verify that documents show a chunk count (meaning they were ingested).

How do I make documents searchable?

Two ways: (1) Manual — upload files on the Documents page; or (2) Automatic — generate documentation in the Nexus Dashboard and click "RAG" to push it to the Knowledge Base.

Can I delete documents?

Yes. On the Documents page, click the trash icon next to a document. It is removed from both the database and the vector store.

What is the difference between Chat and Deep Dive?

Chat quickly searches your documents and returns a concise, cited answer. Deep Dive performs a more extensive, project-focused analysis. Both are available from the input bar on the Chat page.

How do I set up two-factor authentication?

Go to Settings → Security, scan the QR code with an authenticator app, and save your backup codes. If MFA is mandatory in your deployment you will be prompted to enrol at login.

How do I reset my password?

Contact an admin — they can reset your password from the Admin panel.

Which AI models does Nexus use?

Nexus uses a configurable provider chain. A typical cloud configuration uses Voyage AI for embeddings and reranking and a cloud LLM (such as Anthropic Claude) for answers, each with a local Ollama fallback. Deployments that must keep all data on-premise can run fully local with Ollama for both embeddings (nomic-embed-text) and generation (gemma3:12b). See Architecture for how this affects data flow, and check with your administrator which providers are active.
