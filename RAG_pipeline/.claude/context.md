**Status (2026-08-26, answer prose now streams on every tool path):** streaming was never broken -- it was scoped. Token-level text reached the client through one channel (`AnswerDeltaSink`), fed only by `answer_from_documentation`, because that answer is deterministically cited and bypasses the grounding validator, so streamed text provably equals persisted text. Everywhere else the validator may rewrite the answer, so prose was withheld and delivered post-persistence in one burst. Now the outer model's draft streams too, via `_DraftAnswerStreamer` (`readonly_runtime.py`): provisional `replayable=False` deltas that the authoritative post-persistence replay resets and rebuilds, so the stored answer always wins on screen. Three guards make the provisional text safe -- seal at the first "```" so the `nexus-grounding` block is never shown, humanize every emitted character, and screen against `contains_internal_output` (extracted from the validator, shared not copied). Emission is bounded by a safe boundary: last whitespace normally, last **newline** on the topology surface where suppression matches multi-word spans. New `assistant.draft_reset` event retracts a draft the model turned out to be narrating before a tool call, or that the validator rejected. Kill switch: `AGENT_RUNTIME_V2_DRAFT_ANSWER_STREAMING_ENABLED` (default **true**).
